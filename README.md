# RoboFriends

A searchable robot directory built with React and Vite.

## Requirements

- Node.js 20.19 or newer
- npm 10 or newer

## Development

```bash
npm ci
npm start
```

Vite serves the app at `http://localhost:5173` by default.

## Production build

```bash
npm run build
npm run preview
```

Production files are written to `dist`.

## Deployment

Pushes to `master` are deployed to GitHub Pages by the deployment workflow.
